# Document numbers are internal, counted per type and year, and may have gaps

Quotations and invoices are numbered by the database, not by each device, because per-device counters let two devices give two documents the same number (issue 404). Each document type has its own count, and the count restarts each Manila calendar year, so a number such as `INV-2026-0007` is unique by type and year. A number is taken when a manager downloads the PDF; if the download fails or is abandoned, that number is lost, and we accept the gap. We rejected gap-free numbering because it needs a log of every document and a void flow, and these numbers are internal tracking for the family, not an official invoice or receipt series (tax and BIR compliance are out of scope). If the app cannot reach the database, it makes no document rather than guess a number. The resort keeps one shared letterhead in the database for the same reason.
