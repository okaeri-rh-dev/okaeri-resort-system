# Breakpoints use Material 3 window size class names; Tailwind's defaults are removed

Window breakpoints are Material 3 window size classes: compact (the unprefixed base, under 600px), `medium` (600), `expanded` (840), `large` (1200) and `xlarge` (1600), defined as `--breakpoint-*` in `@theme`, and the end state resets Tailwind's defaults with `--breakpoint-*: initial`, so `sm:`, `md:`, `lg:`, `xl:` and `2xl:` stop existing. We chose this because the layout rules (navigation form, pane count, margins) are written against M3's classes, and Tailwind's 640/768/1024/1280/1536 don't line up with them: `md` has no M3 equivalent and `lg` starts 184px after expanded, which is why 840–1023px had no visible navigation. We rejected redefining `sm`/`md`/`lg` to M3 values in place because it would silently shift about 321 existing usages and leave names that mean something else to anyone who knows Tailwind. As with the colour reset (ADR 0003), the defaults are removed last: both name sets coexist during migration, and breakpoint prefixes are only used in layout shells, since content inside a pane responds to its container (`@container`), not the window.
